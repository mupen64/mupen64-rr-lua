# TAS Input

The TAS Input plugin is a built-in input plugin optimized for TASing workflows. 

## Configuration

### M1/M2 bindings

The M1/M2 (magnitude 1/2) bindings limit the magnitude of the joystick on the X/Y axes respectively to the provided value when invoked.
